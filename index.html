복잡도 (Big O)

Big O란

  • n이 커질 때 비교 횟수가 늘어나는 모양. 초 단위 시간이 아님
  • 만드는 법: 비교 횟수 식에서 계수 버리고, 가장 큰 차수만 남김
  • (n−1)n/2 = n²/2 − n/2 → O(n²)

복잡도 한 장 정리 ★

알고리즘Big O이유
sequential searchO(n)최악 n번. 정렬돼도 n
binary searchO(log n)비교마다 범위 절반. 정렬 필수
selection sortO(n²)(n−1)n/2번
bubble sortO(n²)(n−1)n/2번
merge sortO(n log n)log n 라운드 × n번

빠른 순서: O(log n) > O(n) > O(n log n) > O(n²)

차수가 낮을수록 빠름. n=1,000이면 log n≈10, n=1,000, n log n≈10,000, n²=1,000,000

selection sort

  • 남은 것 중 가장 작은 값을 맨 앞으로. 맨 앞 값과 비교해 작으면 바로 맞바꿈
  • [5,9,4,7,3] → 4번 [3,9,5,7,4] → 3번 [3,4,9,7,5] → 2번 [3,4,5,9,7] → 1번 [3,4,5,7,9]
  • 5개면 4+3+2+1 = 10번

bubble sort

  • 세로로 세우고 아래에서부터 이웃끼리 비교. 위가 크면 바꿈 → 작은 값이 위로
  • 한 라운드 끝나면 가장 작은 값이 맨 위에 도착
  • 비교 합 10번, O(n²). selection과 차이: 맨 앞 값과 vs 이웃끼리

재귀

recursion

  • 몸통 안에서 자기 자신을 부르는 함수
  • base case: 자기를 안 부르고 바로 답. recursive case: 더 작은 문제로 자기를 호출
  • while 반복문 팩토리얼은 재귀 아님
  • recursion tree는 왼쪽 가지 먼저 끝까지
  • fib(6) = 8 (1,1,2,3,5,8)
  • 회문: 첫 글자 == 끝 글자 and s[1:-1]도 회문. base는 len(s) <= 1

탐색 · merge sort

binary search

  • 정렬된 리스트만. 가운데와 비교해 절반 버림
  • mid = (low+high)//2
  • 더 크면 mid+1, high / 더 작으면 low, mid-1 (mid는 이미 봤으니 뺌)
  • if low == mid: return False = 왼쪽에 남은 게 없을 때
  • n/2^k = 1 → k = log₂n

merge sort

  • 길이 0·1이면 정렬됨(base) → 아니면 반으로 나눠 각각 merge sort → merge
  • merge: 두 리스트 맨 앞끼리 비교, 작은 쪽을 넣음. 한쪽이 바닥나면 남은 쪽을 그대로 붙임
  • merge 비교 최대 len(left)+len(right)−1 (4+4면 7번)
  • 8개면 log₂8 = 3라운드 × n번 → O(n log n)

selection sort (L15 p.10) 
def selection_sort(L):
    start = 0
    end = len(L)
    while start < end - 1:           # ★
        for i in range(start + 1, end):  # ★
            if L[i] < L[start]:
                L[start], L[i] = L[i], L[start]
        start += 1
    return L
bubble sort (L15 p.16) 
def bubble_sort(L):
    end = len(L)
    for start in range(end - 1):      # ★
        for j in range(end - 1 - start):  # ★
            i1 = (end - 1) - (j + 1)  # 위
            i2 = (end - 1) - j        # 아래
            if L[i1] > L[i2]:
                L[i1], L[i2] = L[i2], L[i1]
    return L

i2는 아래 끝에서 j만큼 올라간 자리, i1은 그 바로 위

binary search (L17 p.12) 
def b_search(L, q, low, high):
    if low == high:
        return L[low] == q
    mid = (low + high) // 2
    if L[mid] == q:
        return True
    elif L[mid] < q:
        return b_search(L, q, mid + 1, high)
    else:
        if low == mid:
            return False
        else:
            return b_search(L, q, low, mid - 1)
merge sort (L17 p.15·17) 
def merge_sort(L):
    if len(L) < 2:
        return L[:]
    mid = len(L) // 2
    left = merge_sort(L[:mid])
    right = merge_sort(L[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i, j = 0, 0
    while i < len(left) and j < len(right):
        if left[i] < right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    while i < len(left):
        result.append(left[i])
        i += 1
    while j < len(right):
        result.append(right[j])
        j += 1
    return result
재귀: fact · fib · 회문 
def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)

def fib(n):
    if n == 1 or n == 2:
        return 1
    return fib(n - 1) + fib(n - 2)

def is_palin(s):
    if len(s) <= 1:
        return True
    return (s[0] == s[-1]) and is_palin(s[1:-1])
